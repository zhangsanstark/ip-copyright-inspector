5）自己重跑与导出

在仓库根目录执行：

```powershell
uv sync --locked
uv run python scripts/check_note_format.py
uv run python scripts/check_handbook_examples.py
uv run python -m pytest
uv run python scripts/run_all_labs.py
```

只读某章时，不必每次跑全书。例如逐轮观察 reduce，再把例子导出到本地修改：

```powershell
uv run python scripts/check_handbook_examples.py --chapter 08 --show-output
uv run python scripts/check_handbook_examples.py --chapter 08 --export .practice/08
uv run python .practice/08/hb08_reduce_first.py
```

导出器不会覆盖已有同名脚本。代码块自动验证不是安全沙箱，也不替代对代码的理解；只运行你信任的内容。修改代码后断言失败，先看它是在提醒预期改变，还是发现了真正错误，不要直接删掉所有断言。
