2）怎样新增一篇

建议文件名使用小写英文与连字符，例如：

- copyright-basics.md
- image-rights-review.md
- content-similarity.md

本目录中的笔记统一使用普通正文排版。主知识点写 `1）`、`2）`，需要细分时写 `2.1`、`2.2`；不使用 Markdown 标题或加粗文字模拟标题。具体见 [排版规则](../note-format.md)。
